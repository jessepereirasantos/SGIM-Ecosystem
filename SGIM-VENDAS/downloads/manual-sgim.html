SGIM Master

Sistema de Gestão de Igrejas e Vendas - Licença Vitalícia

1. Introdução

Seja bem-vindo ao SGIM Master. Este manual foi projetado para ajudá-lo a configurar e operar o melhor sistema de gestão do mercado. O sistema é composto por uma Dashboard de Vendas (onde você está agora) e o Sistema Church (que você baixou).

2. Instalação do Sistema (Hospedagem)

1

Suba o arquivo sgim_master.zip para o diretório raiz da sua hospedagem (geralmente public_html).

2

Crie o Banco de Dados (Passo Crucial): No seu painel (cPanel/HostGator), localize a seção "Banco de Dados" e clique em Banco de Dados MySQL®.

Guia Detalhado: Criando seu Banco no cPanel

  1. Criar Banco: Em "Criar novo banco de dados", digite um nome (ex: sgim_banco) e clique em Criar.
  2. Criar Usuário: Role para baixo até "Usuários MySQL" -> "Adicionar novo usuário". Defina um nome (ex: sgim_user) e uma senha forte. Guarde essa senha!
  3. Vincular (O PONTO MAIS IMPORTANTE): Role até "Adicionar usuário ao banco de dados". Selecione o usuário que criou e o banco que criou. Clique em Adicionar.
  4. Privilégios: Na tela seguinte, marque a opção TODOS OS PRIVILÉGIOS e clique em "Fazer alterações".

*Nota: Cada hospedagem tem um layout diferente, mas a lógica de Criar Banco -> Criar Usuário -> Vincular com Privilégios é universal.

3

Acesse o domínio onde subiu o sistema. Ele redirecionará para o setup.php automaticamente. Insira os dados do banco que você acabou de criar.

3. Configuração de E-mail (SMTP)

Para enviar e-mails de boas-vindas e chaves de licença, você deve configurar suas credenciais SMTP.

Localize o arquivo config/smtp.php e edite as seguintes linhas:

return [
    'host' => 'smtp.titan.email', // Ou o do seu servidor
    'port' => 587,
    'user' => 'seu-email@dominio.com',
    'pass' => 'sua-senha-aqui',
    'from_email' => 'seu-email@dominio.com',
    'from_name' => 'SGIM Master'
];

Nota: Se usar Gmail, ative a "Senhas de App". Caso use Titan, a porta padrão é 587 com TLS.

4. Envio em Massa (WhatsApp Bulk)

O SGIM Master possui integração para envio de notificações via WhatsApp.

  • Configuração: No menu "Configurações" do sistema Church, insira sua API Token da Evolution API ou serviço similar.
  • Envio de Mensagens: Na lista de membros, você pode selecionar múltiplos contatos e clicar em "Enviar WhatsApp".
  • Modelos: Defina templates de mensagens com variáveis como {nome} para personalizar o envio automático.

5. Configuração de Domínio

Onde colocar o domínio? Seu domínio deve apontar para o IP da hospedagem onde o sistema foi instalado.

A
Registro A: Aponte o nome principal (ex: @) para o IP do Servidor.
B
CNAME: Aponte 'www' para o seu domínio principal.

6. Gestão: Membros, Igrejas e Eventos

👤 Cadastro de Membros

Navegue até Membros > Novo Cadastro. Insira fotos, anexos e histórico ministerial. O sistema gera automaticamente um QR Code de identificação para cada membro.

⛪ Cadastro de Igrejas

Gerencie múltiplas congregações. Em Igrejas > Unidades, você pode cadastrar sedes e filiais com CNPJ, endereço e tesouraria separada.

📅 Eventos e Agenda

Crie eventos com inscrições pagas ou gratuitas. Em Eventos > Gerenciar, você pode emitir ingressos e controlar a entrada via app.
